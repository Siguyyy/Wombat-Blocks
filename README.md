# Wombat Blocks project files

- `index.html` is the current app.
- Keep the `blockly/` folder beside it when opening the editor locally.
- `docs/COMMANDS_AND_HARDWARE.md` describes the supported blocks, Wombat port limits, sensors, and preview boundaries.
- `docs/ARCHITECTURE.md` explains the Blockly-to-C and route-preview pipeline.
- `docs/ROBOT_CONNECTION.md` documents the current KISS IDE workflow and what direct robot execution would require.
- `HISTORY.md` indexes preserved checkpoints in `history/iterations/`.
- `CONTRIBUTING.md` describes the block implementation and hardware review workflow.

No project license has been selected. The Blockly distribution carries its own Apache 2.0 license at `blockly/LICENSE`.
