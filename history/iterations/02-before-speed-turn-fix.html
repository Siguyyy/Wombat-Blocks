Robot setup

Enter measurements from your assembled robot. The build guide shows the claw linkage but gives no finished reach dimensions. Chassis width and wheel track are different: track is wheel-center to wheel-center; width is the robot's widest outside measurement.

Servo presets and claw model · estimates

For your exact build, measure from the front chassis edge to the claw tips when extended. The guide's assembly steps do not specify this finished dimension; the preview defaults are estimates. The model shows linkage and jaw opening, not vertical height or servo torque.

Drive a measured straight distance on the competition surface and adjust each side scale from observed travel. Recheck under normal payload. Encoder feedback cannot correct wheel slip, floor changes, or varying battery condition.

Wombat Blocks

  1. Drag a block from the toolbox into the workspace. Connect it to the start block. Use Restore start block if it is missing.
  2. Stack blocks to move a whole routine. Use Repeat to contain reusable action sequences.
  3. The map uses centimeters from the robot's starting point: X is right, Y is forward. A point 10 cm left and 30 cm ahead is X −10, Y 30.
  4. Type coordinates and dimensions to place an obstacle exactly. Select and drag it to adjust position, or edit its X/Y/size below the map.
  5. The robot position readout follows the preview. Its claw reach and opening are estimates you can edit in Robot setup.
  6. Distance blocks use the measured speed and support encoder-controlled MAV or motor PWM. A direct motor block takes signed MAV ticks/s or motor percent; use Stop afterward.
  7. Use View generated C to switch between the block commands and the full KIPR file.
